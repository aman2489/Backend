- Why NextJs: SEO -> Search Engine Optimization
    - SEO depends on Google

- Step to reach SEO:
    There are infinite number of websites registered
    1. Crawling -> google manages by crawling with bots: Goes on every webisites and figures out which website relies in which genre and then...

    2. Indexing -> It indexes those websites according to genre, keywords, SEO , Delivery(SSR or CSR or ISR or SSG)

    3. SEO -> and then these upper points decides your SEO
        - It has google bots also been known as cert bots earlier
        - Bots demands SSR first then demands other things then
            - SSG(Static Site Generation) -> normal static HTML pages
            - CSR(Client Side Rendering) -> React
            - ISR(Increamental Site Regeneration)


- Import for SEO
    - SSR -> Google bots watches which website sends, renders data first sets on top.
        - React -> Executes on Client(Browser)
        - Next -> Executes all components on server

    - and more things

        6. Ratings and more...
